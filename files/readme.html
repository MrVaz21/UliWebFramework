Материалы для дискретной математики (КР)

1. Принципы индукции

ПМИ (Принцип математической индукции)
Если P(0) и ∀n (P(n) → P(n+1)), то ∀n P(n).
Через множества: если 0∈X и ∀n (n∈X → n+1∈X), то X=ℕ.
ПНЧ (Принцип наименьшего числа)
∃n Q(n) → ∃n (Q(n) ∧ ∀m (m < n → ¬Q(m))).
Иначе: любое непустое подмножество ℕ имеет наименьший элемент.
Эквивалентно: если X⊆ℕ, X≠∅, то ∃min X.
ПСИ (Принцип сильной индукции)
∀n ((∀m (m < n → P(m))) → P(n)) → ∀n P(n).
Или с базой: P(0) и ∀n ((∀m<n P(m)) → P(n)) ⇒ ∀n P(n).
На шаге можно предполагать все P(m) для m < n, а не только P(n−1).
Эквивалентность: ПМИ ⇔ ПНЧ ⇔ ПСИ.
Док-во ПНЧ ⇒ ПМИ: пусть есть контрпример, берём наименьший n₀ с ¬P(n₀). Тогда для m<n₀ P(m). Если n₀=0 — противоречие с P(0); если n₀=m+1 — противоречие с шагом.
Док-во ПМИ ⇒ ПСИ: вводим Q(n) = ∀m<n P(m) и доказываем ∀n Q(n) обычной индукцией.

2. Деление с остатком

Теорема. Для любых a∈ℤ, b∈ℤ, b≠0, существуют единственные q∈ℤ и r∈ℕ такие, что a = bq + r, 0 ≤ r < |b|.
q — неполное частное, r — остаток.
Следствие. a mod b — остаток от деления a на b, 0 ≤ a mod b < |b|.
Пример: −59 = −11·6 + 7, значит −59 mod 11 = 7 (остаток всегда неотрицателен).

3. Сравнение по модулю

Определение. Пусть m > 1. Говорят, что a сравнимо с b по модулю m, если m | (a − b).
Обозначение: a ≡ b (mod m).
Эквивалентные определения:
• a ≡ b (mod m) ⇔ a mod m = b mod m.
• a ≡ b (mod m) ⇔ ∃k∈ℤ: a = b + mk.

Свойства (m > 1):
1) a ≡ a (mod m) — рефлексивность.
2) a ≡ b ⇒ b ≡ a — симметричность.
3) a ≡ b, b ≡ c ⇒ a ≡ c — транзитивность.
4) Если a ≡ b и c ≡ d, то a+c ≡ b+d, ac ≡ bd.
5) Если a ≡ b, то aⁿ ≡ bⁿ (mod m) для n∈ℕ.
6) Числа 0, 1, …, m−1 попарно не сравнимы по модулю m.

4. Делимость

Определение. a | b (a делит b), если ∃k∈ℤ: b = ak.
Свойства:
1) a | 0, ±1 | a, a | a.
2) 0 | a ⇒ a = 0.
3) a | b и b | c ⇒ a | c (транзитивность).
4) a | b и a | c ⇒ a | (b ± c).
5) a | b и b | a ⇒ a = ±b.
6) Если a | b и a | (b+c), то a | c.

5. Простые числа и разложение

Простое число — n > 1, которое делится только на ±1 и ±n.
Составное — n > 1, не являющееся простым (т.е. n = km, 1 < k,m < n).
Основная теорема арифметики (ОТА).
Любое n > 1 единственным образом (с точностью до порядка множителей) представляется в виде n = p₁α₁ p₂α₂ … ptαt, где pi — попарно различные простые, αi ∈ ℕ.
Степень простого p в разложении n: deg(p, n) = α, если pα || n (т.е. pα | n, но pα+1 ∤ n).
Пример: 40 = 2³·5¹ ⇒ deg(2,40)=3, deg(5,40)=1, deg(7,40)=0.
Критерий делимости через разложение.
Для a,b ≠ 0: a | b ⇔ ∀p (простое) deg(p,a) ≤ deg(p,b).
Бесконечность простых. Если p₁,…,pn — все простые, то N = p₁…pn + 1 не делится ни на одно pi, противоречие.

6. Признаки делимости

На 2последняя цифра чётная (0,2,4,6,8)
На 3сумма цифр делится на 3
На 4последние две цифры образуют число, делящееся на 4
На 5последняя цифра 0 или 5
На 6делится на 2 и на 3
На 8последние три цифры образуют число, делящееся на 8
На 9сумма цифр делится на 9
На 10последняя цифра 0
На 11разность суммы цифр на чётных и нечётных местах делится на 11
Пример на 11: 12341: (1+3+1) − (2+4) = 5 − 6 = −1, не делится.
2541: (2+4) − (5+1) = 6 − 6 = 0 ⇒ делится.

7. Дополнительно (полезно)

НОД и НОК.
gcd(a,b) = ∏ pmin(αp, βp), lcm(a,b) = ∏ pmax(αp, βp).
gcd(a,b)·lcm(a,b) = |ab|.

Алгоритм Евклида. gcd(a,b) = gcd(b, a mod b).

Взаимная простота. a и b взаимно просты ⇔ gcd(a,b)=1 ⇔ ∀p min(αp,βp)=0.

Сокращение сравнений. Если ac ≡ bc (mod m) и gcd(c,m)=1, то a ≡ b (mod m).
Формулы для запоминания:
• a ≡ b (mod m) ⇔ m | (a−b).
• a | b ⇔ ∃k b=ak.
• ПМИ: P(0) ∧ ∀n(P(n)→P(n+1)) ⇒ ∀n P(n).
• ПНЧ: X≠∅ ⇒ ∃min X.
• ПСИ: (∀n((∀m<n P(m))→P(n))) ⇒ ∀n P(n).
• ОТА: n = p₁α₁…ptαt единственно.
